# The Manage Her®

Website for The Manage Her® — a women's leadership movement and media brand founded by
Aimee Rickabus. React + Vite + TypeScript, deployed to Cloudflare Pages.

See `CLAUDE.md` for the full project guide: commands, blog post data shape, analytics and
monitoring, and the brand design system.

## Commands

- `npm install` — Install dependencies
- `npm run dev` — Start dev server
- `npm run build` — Production build
- `npm run lint` — ESLint check
